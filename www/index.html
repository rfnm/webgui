firmware update

⚠ update mode is armed — the next reboot enters the firmware updater
reinstalls the board firmware from scratch: the board reboots into its built-in recovery (purple LEDs), downloads and installs the standard release firmware by itself when its network has internet access — or installs a .swu file from a USB stick — then reboots back to normal operation. everything stored on the board is replaced. note: if this board runs a beta build, the automatic download restores the older release version — to stay on beta, install the beta .swu from a USB stick instead.
